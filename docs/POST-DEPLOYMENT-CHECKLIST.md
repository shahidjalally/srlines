# After merging the SRLINES website update

1. Check the GitHub Pages deployment for the merge on `main`. Confirm the homepage, flagship, six landing pages, wCRM pages, forms, product links, demo and mobile menu on the public domain. Check the root sitemap, robots file and optional discovery file. Use [the Pages runbook](pages-deployment.md) if publishing stalls.
2. Check HTTP-to-HTTPS and www-to-canonical redirects. Inspect HTTP status and X-Robots-Tag on public routes, and confirm missing pages return a 404. Spot-check canonical URLs.
3. Submit `https://srlines.net/sitemap.xml` through Google Search Console and Bing Webmaster Tools. Inspect and request indexing for the homepage, flagship and six new pages. Record inspection status and crawl dates. Configure IndexNow for changed URLs if the owner adopts it and can host its ownership key.
4. Check the effective public robots file and Cloudflare AI Crawl Control, managed robots, firewall and bot analytics. Verify intended public access for Googlebot, Bingbot and OAI-SearchBot. Check ChatGPT-User separately for user-initiated requests. GPTBot is a distinct training crawler. Review its effective access with the owner before changing company policy. [OpenAI crawler documentation](https://developers.openai.com/api/docs/bots) · [Cloudflare managed robots](https://developers.cloudflare.com/bots/additional-configurations/managed-robots-txt/)
5. Validate representative company, product, industry and pricing graphs with Schema.org Validator. Use Google's test to check applicable rich-result eligibility. Confirm the YouTube video is playable while logged out and embeddable. The video graph appears once the original public upload date is available from the uploader. Retest the homepage, PBX page, selected product pages and partner directory after the structured data update is deployed.
6. With owner-approved test data, submit one quotation and one consultation through the production wCRM form. Confirm receipt and look for one lead event for each successful submission. Confirm telephone and WhatsApp actions use the official number and WhatsApp measurement fires.
7. Align external profiles and publish the approved Hugo articles. Verify their actual canonicals and add links from the main site. See [profile alignment](EXTERNAL-PROFILE-ALIGNMENT.md) and [blog handoff](../content/blog/README.md).
8. Record Search Console impressions, visits, qualified enquiries, conversion rates and field Core Web Vitals where volume permits. Review ChatGPT Business Hub Brand Insights if available. Repeat the [discoverability protocol](AI-DISCOVERABILITY-TESTS.md) after crawling and again after 30–60 days.

Rollback by reverting the merge with a reviewed PR and checking the next Pages deployment. Keep custom domain and Pages settings. If an emergency rollback must preserve the UAN correction, include the corrected contact configuration in the rollback PR.
