# SRLINES AI discoverability testing

## Baseline

The brief’s sampled ChatGPT tests found SRLINES in branded and local searches. Answers emphasized WhatsApp CRM, ecommerce automation and a conventional PBX. The sampled national AI calling recommendation omitted SRLINES. Sample dates, individual answers and citation URLs were unavailable. Treat the observations as a qualitative baseline.

On 26 November 2026, a separate web search sample surfaced the [older SRLINES homepage](https://srlines.net/) and [company LinkedIn profile](https://www.linkedin.com/company/srlines-software-house-smc-pvt-limited) for branded search. The generic queries “AI calling agent providers Pakistan Urdu AI voice agent provider” and “AI receptionist Pakistani businesses AI PBX provider Pakistan” surfaced providers such as [Pukaar](https://www.pukaar.io/) and [Conciara](https://conciara.com/en/pk) alongside other results. That search did not surface the SRLINES PBX product page in the returned sample. This is a web search observation, separate from the ChatGPT baseline.
